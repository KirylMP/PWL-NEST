# Меньше порогов: AM 2C и FM 4C

[Результаты SIC и скорости](../results/threshold_reduction/REPORT.md).
Это исследование компактных приближений; точное совпадение с LR не требуется
и не заявляется. Старые кандидаты остаются сохранёнными.

Для AM проверены обе геометрии: два C-порога без IP3-порогов (3 области)
и два C-порога с I-узлами .35,.64 (9 областей). В каждой — h³ и ln(h).
Для FM четыре C-порога дают пять областей, координаты C,h остаются аффинными.

Координаты, их нормировки, непрерывный hinge-базис и точное экспоненциальное
IP3 сохранены. Последовательность региональных спектральных типов не
фиксируется. Два интерсепта выводятся из точного устойчивого покоя LR.
Положительная связь v→u и отрицательное самодействие v сохраняются.
Упорядоченные C-пороги и оставшиеся коэффициенты подбираются заново.
Итого 12/16 параметров для двух AM-геометрий и 18 для FM.

Полевая инициализация перебирает все подмножества исходных порогов:
по три подмножества AM и 35 FM. Для каждого есть две проекции: исходного
кандидата и преобразованного LR-поля. Получается по 6 и 70 стартов.
Проекция исходной модели сохраняет gate-столбец и, если оставлены I-узлы,
их веса. Начальная устойчивость покоя восстанавливается в проекции.
Это инициализация, а не ограничение спектров остальных областей.

Используются только фиксированные и динамические обучающие траектории.
Два лучших старта уточняются least_squares и локальным Powell, максимум
1000 вызовов остатка на стадию. Фактические оценки и ранние остановки
сохранены. Стартовые и уточнённые кандидаты перепроверяются DOP853;
выбор — по независимо пересчитанному train-loss, без SIC-тестов и timing.

Общий критерий сравнения — физическая часть прежнего RestObjective:
автономные режимы, покой, высоты/ширины/интервалы/числа пиков, первая
задержка и слабый поточечный остаток. Спектральные якоря отдельных границ
отключены для обеих сторон: при другом числе порогов нет прежнего
взаимно однозначного соответствия. Поэтому новый loss не равен старым
числам. Полные контрольные модели заново оценены тем же общим критерием.

Сравнение с замороженными полными моделями не является чистой абляцией
числа порогов: меняются спектральные ограничения и условие точного покоя.
По этим данным нельзя приписывать улучшение или ухудшение только числу
областей. Глобальная оптимальность поиска также не доказана.

Пять новых протоколов на случай заданы в evaluation_plan.json: tau11/32/72/150
и нерегулярный поток с seed=20261027. В NEST подаются одинаковые спайки,
каждая модель начинает из собственного устойчивого покоя. Проверяется
доставленный I_SIC целевого AEIF, а не только readout C. Полные траектории
сохраняются. Диагностики не меняют train-выбор внутри каждой геометрии.

Timing: 64 независимые пары, один поток, шаг 1 мс, 60 с, три повтора
после прогрева, запись отключена. Build и Prepare исключены и сохранены
отдельно. Изолированные C++-ядра имеют три повтора без отдельного прогрева.
Редкие взвешенные спайки воспроизводят входные скачки IP3.

В обычном тике аналитический пропагатор по-прежнему представляет собой
матрицу 4×4. Уменьшение числа областей в основном сокращает выбор области,
число некоторых пересечений и подготовку кеша, а не размер этого умножения.
Целевые нейроны также остаются в полной сети. Поэтому меньше порогов
не гарантирует пропорционального ускорения всей сети.

```bash
export PYTHONPATH=src:scripts OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
export MPLCONFIGDIR=/tmp/nest-matplotlib XDG_CACHE_HOME=/tmp
bash scripts/setup.sh
# Требуется установленный NEST и собранный модуль: docs/nest_module.md.
.venv/bin/python scripts/run_reduced_search.py \
  --output results/threshold_reduction --workers 4 --budget 1000 --starts 2
.venv/bin/python scripts/evaluate_reduced_thresholds.py
# Только перестроить отчёт по уже сохранённым данным:
.venv/bin/python scripts/evaluate_reduced_thresholds.py --report-only
```

Для повторного поиска нужен новый --output. Полные исходные модели и
новые JSON расположены в models/; каталоги опыта содержат screening,
каждую независимую проверку, параметры, checkpoints и сырые времена.
Для статьи: [какие выводы уже подтверждены](article_claims.md).
