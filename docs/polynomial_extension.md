# Отдельное направление: полиномиальный вход

Источник: сообщение пользователя с описанием стороннего пробного расчёта. Исходники,
коэффициенты и результаты этого расчёта не предоставлены; числа 8/11 и ошибки
траекторий здесь не воспроизведены. Эти кандидаты не включены в стартовые модели.

Предложенный класс:
Cdot = w + G(C) + p(I), wdot = Q(C) + r(I),
Idot = -(I-I_inf)/tau, tau > 0.
G,Q — непрерывные ломаные с постоянными коэффициентами.
При постоянных I_inf,tau и полиномах степени d можно ввести
u=I-I_inf, z_m=u^m, m=1,...,d. Тогда zdot_m=-(m/tau)z_m.
Состояние (C,w,1,z_1,...,z_d) подчиняется постоянной линейной матрице
внутри региона. Собственные значения не обязаны быть вещественными или соизмеримыми.
Это точное аналитическое вложение, но не аффинное поле в исходных (C,w,I).
Также w не является физической переменной инактивации h.

При скачке I+=DeltaI необходимо обновлять z_m=(I+-I_inf)^m,
сохраняя C,w при выбранном физическом законе скачка. Cdot может скачком
измениться через p(I); сопоставление начальных C,Cdot не проверяет такой скачок.
При смене I_inf нужно пересчитать вложенные переменные и матрицы.

Для кусочно-полиномиального входа добавляются границы по I. Время узла I_b:
t=-tau*log((I_b-I_inf)/(I_0-I_inf)); допустимы только положительные времена
с отношением строго между 0 и 1. При I_0=I_inf пересечений нет.
Для непрерывности p,r значения соседних полиномов на узле должны совпадать.
Первое пересечение границы C всё равно требует надёжной локализации корня.

Необходимые будущие проверки: лишние циклы, слабые AM-циклы у onset,
верхняя граница циклов, положительность при спаде входа, FM, скачки IP3,
отдельные train/holdout стимулы и измерение полной стоимости вычислений.
