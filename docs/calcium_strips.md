# Исходная спектральная эвристика: компактные C-полосы

Исследуем ровно ту эвристику, которая использовалась в legacy:
при фиксированном I находим равновесия Li–Rinzel в (C,h), вычисляем их 2×2
якобиан, на равновесной кривой ищем смену типа и фиксируем соответствующее C.
Учитываются trace=0 при det>0, det=0, discriminant=0. В FM при одном I может
быть несколько равновесий; прослеживается вся ветвь, параметризованная C,
а не только одно равновесие, выбранное численным решателем.

AM: C=[.1119526454033, .1556894888083, .3233038346842], 4 области.
FM: C=[.0486193511137, .0521411627215, .0548446931276, .0612893091096,
.1357042423799, .2518184157527, .3926251934102], 8 областей.
AM-порог .25 из контрольной legacy-модели не является спектральным и здесь
не добавляется. Все пороги постоянны для всех I и всех траекторий.

## Строгий класс

X=(C,h,I) — физические координаты. Для первых двух компонент:

F(X)=b+a_C C+a_h h+a_I I+sum_j u_j max(0,C-theta_j).

Третья компонента ровно Idot=-(I-I_b)/tau. Внутри каждой C-полосы это
постоянная аффинная система. На общих плоскостях поле непрерывно для любых
h,I. Никаких полиномов, параметрического пересчёта коэффициентов по I,
дополнительных h/I-порогов и тетраэдров нет.

Для соседних полос: ΔA=u e_C^T, Δb=-u theta. Значит, столбцы при h,I
обязаны быть общими. Это ограничение точной непрерывности на всей плоскости,
а не дополнительная эвристика. Региональные коэффициенты физической модели
экспортируются методом `local_coefficients`; `region` возвращает полные A,b.

Две строки × (4+m) коэффициентов: 14 свободных параметров AM, 22 FM.
Пороговые константы определены исходной системой и не оптимизируются.
Tau и I_b задают протокол и не входят в число подбираемых параметров.

## Спектральная параметризация и старт

В каждом регионе задаются trace mu_j и determinant k_j кальциевого якобиана,
общие B=a_h^C>0, D=a_h^h<0, коэффициент c_I=a_I^C и константа c_0.
Из них восстанавливаются a_C^C=mu-D и a_C^h=(D*a_C^C-k)/B.
Остальные свободные параметры: q0 и q_b>0, где
q_j=B*b_h,j-D*b_C,j, q_b=B*a_I^h-D*a_I^C.
Непрерывность задаёт q_{j+1}-q_j=(k_{j+1}-k_j)*theta_j.
Это эквивалентно шарнирной записи; всё поле остаётся аффинным в физических X.
Знаки B,D,q_b и знаки trace/determinant — явные ограничения первой попытки,
не доказанная необходимость для всех возможных компактных моделей.

Как в legacy, спектр LR усредняется с весом |dI| вдоль каждого интервала
равновесной ветви. Непрерывная восстанавливающая сила инициализируется по
хордам обратной равновесной кривой I_eq(C), со скалярной регрессией на
средние детерминанты. Физическое h сохраняется; его масштаб и сдвиг не
объявляются новой переменной — коэффициенты B,D,c_I,c_0 подбираются по LR.

## Две попытки подбора

v1 (`fit_strips.py`): спектральный и field-LS старты, совместный подбор
автономных метрик и экспоненциальных траекторий; source node/focus подтипы
имели только мягкий штраф. Эта попытка не прошла динамическую проверку.
Её исходные результаты и модели сохранены в `joint_v1`, не удалены.

v2 (`refine_strips.py`):
1. Жёстко закреплены исходные региональные типы. Для focus задаётся
   k=mu²/4+exp(z), для node k=(mu²/4)*sigmoid(z), для saddle k<0.
2. Сначала подбираются автономные экстремумы/периоды и I-координаты пересечений
   равновесной кривой с порогами. Два локальных старта, least_squares и Powell.
   На этом промежуточном этапе Cdot0=0 используется только как способ выделить
   привлекающую ветвь — это не проверка совпадающих физических начальных состояний.
3. После восстановления физического поля выполняется совместный подбор по
   одинаковым физическим (C,h,I), двум экспоненциальным спадам и нарушениям
   физических диапазонов. Два local least_squares старта и Powell.

Train: AM I=.3,.4,.5,.6,.7; FM I=.48,.55,.7,1,1.2; фиксированные прогоны
1600 с. Начальные (C,h)=(.6,.8) AM и (1.3,.8) FM одинаковы у LR и PWA.
Динамические train: tau=20,100 с, 180 с, C0=.08,h0=.8;
AM I0=.65,I_b=.3; FM I0=1.15,I_b=.45.

Масштабы residual v2: Cmin=.02 мкМ, Cmax=.05 мкМ, период=1 с AM/3 с FM;
для неподтверждённого обязательного цикла добавляется 15, а не нулевой штраф.
Покой штрафуется по размаху/.02. Отрицательный C:/.005, h:/.01,
выход C выше физической C_max:/.02. I-координаты равновесных переходов:/.03.
Динамические траектории нормированы по [.03 мкМ,.05] для C,h и sqrt(N).
Слабая regularization .005 к автономному старту. Конкретные bounds и алгоритм
сохранены в исходниках; оптимизация локальная, не исчерпывающая.

Holdout-протоколы те же диагностические, что в плотном эксперименте:
пять других фиксированных I, tau=2,50 с, периодические/нерегулярные скачки
с прекращением входа. Полные списки есть в результатах JSON.
Из-за просмотра v1 holdout перед изменением процедуры v2 это не слепая проверка.
Ни один кандидат не принят только по малой обучающей функции потерь.

## Аналитичность и независимая валидация

`regional_flow` использует exp(t*[[A,b],[0,0]]), без обращения A и без
требования соизмеримого или вещественного спектра. Его корректность проверена
для сохранённых моделей. I(t)=I_b+(I0-I_b)*exp(-t/tau) точно.
При скачке меняется только I; C,h не меняются.

Для быстрого подбора при постоянном I используется внутренний расчёт в
(C,v=Cdot), где vdot=mu_j*v-k_j*C+q_j+q_b*I. Это вспомогательная координата
решателя, не подмена физического h в модели. Начальное v берётся из полного
физического поля, кроме явно отмеченного промежуточного автономного этапа.
Legacy engine распространяет состояние аналитически внутри региона и
локализует пересечения границ. Проверка полных физических траекторий — DOP853.

Динамический fit использует C++ RK4 для C,h с точным значением I на каждой
стадии; maxdt=.025 с, автоматически уменьшается для больших собственных
масштабов. Это ускоритель подбора, не заявленный аналитический решатель.
Независимая проверка v2 использует DOP853 rtol=2e-9,atol=2e-11,max_step=.15 с;
дополнительно сравниваются RK4 с maxdt=.005 и DOP853 в одни и те же моменты.
Полный аналитический событийный интегратор с первым выходом — следующий этап.

Валидатор сохраняет нарушения C>=0, C<=2/1.185, 0<=h<=1, не обрезая их.
Для компактных моделей нет доказательства глобальной инвариантности коробки.
`enforce_domain=False` разрешает диагностировать вышедший из неё кандидат,
а не объявлять такой результат успешной физической моделью.

## Воспроизведение

Из /workspace/PWL-NEST:

```bash
bash scripts/setup.sh
.venv/bin/python -m unittest discover -s tests -v
# Повторить v2, используя сохранённые v1 старты:
OPENBLAS_NUM_THREADS=1 .venv/bin/python scripts/refine_strips.py
OPENBLAS_NUM_THREADS=1 .venv/bin/python scripts/check_strips.py
.venv/bin/python scripts/summarize_strips.py
# Независимо повторить только проверки траекторий:
OPENBLAS_NUM_THREADS=1 .venv/bin/python scripts/validate_strips.py
```

Эксперимент перезаписывает текущие v2 результаты; архив `joint_v1` не меняется.
Полная отдельная v1 попытка запускается `scripts/fit_strips.py` и перезаписывает
текущие корневые модели/результаты, поэтому она не входит в обычный startup.
Результат: `results/calcium_strips/REPORT.md`. Он включает неудачные проверки.
