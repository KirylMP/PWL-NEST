# FM: один подбираемый порог по I

Сохраняется координата identity по C и h и исходные восемь C-полос.
К двум правым частям добавляется непрерывный hinge:

```
F(u,v,I) = F0(u,v,I) + (a,b) max(0, I - eta).
dI/dt = -(I - I_inf)/tau.
```

Подбираются eta, a и b вместе с прежними коэффициентами и семью упорядоченными
C-порогами: 32 параметра вместо 29. В коде b выражается через положительное
отношение input-gain `exp(lambda)`; это два свободных коэффициента hinge,
с ограничением на положительный наклон восстанавливающей силы по I.
Eta ограничена (.46,1.12), а ratio gain — от 1/4 до 4.
Новые варианты имеют 8×2=16 регионов, контроль — 8.

Внутри каждого региона полная трёхмерная матрица постоянна. Hinge изменяет
I-колонку и смещения, сохраняя C,h-блок якобиана при переходе I-порога.
Прежняя параметризация спектральных типов C-полос сохраняется.
На непрерывном отрезке входа время пересечения eta вычисляется явно:

```
t_eta - t0 = tau * log((I(t0) - I_inf)/(eta - I_inf)).
```

Формула применяется только к достижимому порогу внутри текущего отрезка.
Скачки I начинают новый отрезок; C/h непрерывны. Региональное движение считается
через экспоненту аффинной матрицы. Это не добавляет полный решатель первого
выхода через C-порог: соответствующий поиск корня по-прежнему нужен.

## Данные и критерий

Обе семьи начинают с одного замороженного кандидата
`models/server_candidates/FM_identity__identity.json`.
Сохраняются собственный устойчивый покой и 20 с задержки входа.
Ни C, ни h не обрезаются.

К прежнему критерию добавлены абсолютные времена пиков и явное окончание пачки:
время последнего пика и избыток C над LR после последнего LR-пика + 5 с.
Для последнего остатка задан допуск 0.02 мкМ. Прежний штраф числа пиков не ослаблен.

Прежние неудачные проверки tau=35,65,80 **явно переведены в обучение**.
Они дополняют tau=20,100 и периодический вход, итого шесть динамических протоколов.
Сохраняются восемь автономных проверок и прежние мягкие спектральные I-якоря.
Модели выбираются по независимо пересчитанному DOP853 train loss среди тех,
у кого совпадают все обучающие числа пиков, известные автономные режимы и
проходят физические проверки на сетке выдачи. Если таких нет, результат
помечается только как диагностический.

Новые тесты: tau=9,28,57,95,170 и новый нерегулярный вход с tau=23,
seed=20261024. Тестовые метрики не выбирают кандидата.
Полевая инициализация использует **только фиксированные и динамические
обучающие траектории**. Старый field.npz из переданного cache игнорируется
и перестраивается. В data.json перечислены все протоколы, давшие точки поля.

## Бюджет и инициализация

Первый проход: по три старта на семью и budget=1500 на каждую стадию оптимизации.
Начальные I-пороги берутся из I последнего LR-пика на обучающих tau=20,100
и их среднего: примерно .6058,.6282,.6506. Нулевые hinge-коэффициенты точно
воспроизводят исходную модель. RNG у парных стартов одинаковый.

При нулевом hinge положение eta сначала неидентифицируемо, и локальный подбор
почти его не сдвигал. Поэтому выполнен дополнительный **равный для обеих семей**
трёхмерный поиск differential_evolution: 24 особи, до 25 поколений, 624 оценки,
затем ещё budget=1500 на совместное уточнение всех параметров.
У hinge-семьи исследуются eta и два коэффициента hinge. У контроля — три уже
имеющихся параметра входного воздействия (offset, log(qb), cI).
Эта стадия назначена по поведению оптимизатора на обучении, не по тестовой ошибке.
Первый проход сохранён в `first_pass/` отдельно.

## Запуск

Нужны зависимости и native-модули, собранные как для прежнего grid.
Из корня проекта:

```bash
PYTHONPATH=src:scripts OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  .venv/bin/python scripts/fit_fm_input_threshold.py \
  --output runs/fm-one-input-knot --budget 1500 --workers 3
```

Если есть старый cache, можно добавить `--reference-cache /path/to/run/cache`.
Его поле инициализации всё равно перестраивается по train-only данным.
Дополнительная широкая инициализация, по одному процессу на семью:

```bash
PYTHONPATH=src:scripts OPENBLAS_NUM_THREADS=1 \
  .venv/bin/python scripts/warmstart_fm_input_threshold.py \
  --output runs/fm-one-input-knot --family control

PYTHONPATH=src:scripts OPENBLAS_NUM_THREADS=1 \
  .venv/bin/python scripts/warmstart_fm_input_threshold.py \
  --output runs/fm-one-input-knot --family one_I_knot

PYTHONPATH=src:scripts OPENBLAS_NUM_THREADS=1 \
  .venv/bin/python scripts/fit_fm_input_threshold.py \
  --output runs/fm-one-input-knot --stage evaluate

PYTHONPATH=src .venv/bin/python scripts/audit_input_threshold.py runs/fm-one-input-knot
.venv/bin/python scripts/plot_fm_input_threshold.py runs/fm-one-input-knot
```

Результаты этой серии: `results/fm_one_input_threshold/README.md`.
