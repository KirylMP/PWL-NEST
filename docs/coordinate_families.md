# Экспонента, логарифм и обратные степени C; log/exp для h

Продолжение опытов с преобразованными координатами. Цель — проверить другие
формы координат при исходной эвристике спектральных C-порогов. Порогов по I
и дополнительных плоскостей нет: AM 4 области/14 параметров, FM 8/22.

## Два этапа сравнения

1. Пять преобразований C при logit(h): sqrt (контроль), exp, log, inverse,
   inverse_sqrt. Все пять подбираются заново при прежнем бюджете.
2. Для лучшего C по обучению отдельно подбираются log(h) и exp(h).

Это семь моделей на case, не полная декартова сетка C×h. Итог выбирается
по общей обучающей потере без регуляризации; диагностики не участвуют.
Лучший C оказался sqrt для AM и FM. Итоговый h по обучению — log для AM,
exp для FM. Эти кандидаты ещё не прошли приёмку.

## Нормировки и области определения

Все преобразования C возрастающие, центрированы в исходном равновесии Cref
при I=0 и нормированы так, чтобы phi(Cmax)=Cmax, Cmax=2/1.185 мкМ.
Нормировка фиксирована, не подбирается. Для степеней p=.5,−1,−.5:

\[
f_p(C)=\frac{C_{ref}}p[(C/C_{ref})^p-1],\quad
s=\frac{f_p(C_{max})}{C_{max}},\quad u=f_p(C)/s.
\]

Для p<0 это −1/C или −1/√C с постоянными сдвигом и положительным масштабом:
знак выбран для возрастания координаты. Он не меняет класс преобразования.
Обратная ветвь требует 1+p*s*u/Cref>0. Для p>0 есть нижняя конечная граница
u=−Cref/(p*s), соответствующая C=0. Для p<0 есть верхняя граница
u=−Cref/(p*s), соответствующая C→∞; C→0 даёт u→−∞.

Для log: f(C)=Cref*ln(C/Cref). Для exp:
f(C)=Cunit*[exp((C−Cref)/Cunit)−1], Cunit=1 мкМ. В обоих случаях u=f/s
и s=f(Cmax)/Cmax. В коде C задан числом мкМ, поэтому Cunit=1.
Это exp(C/Cunit) с фиксированным аффинным центрированием. Параметр крутизны
экспоненты не подбирается. Для exp нижняя граница соответствует C=0.

Все варианты h центрированы в href и имеют ту же локальную производную,
что logit(h), при h=href:

\[
v_{logit}=\ln\frac h{1-h}-\ln\frac{h_{ref}}{1-h_{ref}},\quad
v_{log}=\frac{\ln(h/h_{ref})}{1-h_{ref}},\quad
v_{exp}=\frac{\exp(h-h_{ref})-1}{h_{ref}(1-h_{ref})}.
\]

Нормировка сохраняет касательное соответствие предыдущему warm start без
нового параметра. Обратные функции: sigmoid, href*exp((1−href)*v) и
href+ln(1+href*(1−href)*v). Для log есть конечная верхняя граница v при h=1;
для exp обе границы конечны. Проверяются именно 0<h<1, а не только область
определения обратного логарифма. Ни C, ни h не обрезаются.

В native RK4 добавлен отдельный box-API: ограничения u и v проверяются на
каждом принятом внутреннем шаге. Старые API сохранены. Независимый DOP853
останавливается по событиям выхода из допустимой ветви или из 0<h<1.
Обратные степени могут давать большие u при малом C; native дополнительно
имеет численный предел |u|,|v|<=20. Это guard ускорителя, а не физический
порог; его срабатывание не означает, что физическое C стало отрицательным.
Полная проверка DOP853 имеет отдельный runaway guard C=20 мкМ или |v|=100.

## Поле, аналитичность и проверка

Точное преобразованное LR-поле:
udot=phi'(C)*fC, vdot=psi'(h)*fh, Idot=−(I−Ib)/tau.
Подбирается непрерывная PWA в (u,v,I) с теми же source-спектральными типами.
Внутри региона A,b постоянны, движение задаётся матричной экспонентой.
Физические пороги Ck превращаются в uk=phi(Ck); h-порогов не добавляется.
Преобразование не зависит от I, скачки сохраняют u,v и физические C,h.
Восстановленное физическое поле не является PWA.

Training: прежние 5 фиксированных I и два экспоненциальных спада tau=20,100.
Общие residual scales, три старта, уточнение двух до 120 nfev каждого,
Powell до 2400 вызовов описаны в [предыдущем методе](calcium_coordinates.md).
Точный source-field residual переводится в физические скорости через
diag(1/phi',1/psi'). h-экстремумы автономного fitting helper измеряются в
событийных точках; это приближение, окончательные диапазоны проверяет DOP853.

На каждую модель — 20 протоколов, включая 13 исторических диагностик.
Эти данные уже известны, слепой проверки нет. Результат относится к
локальному поиску с конечными bounds и бюджетом. Даже неизменный класс
при аффинной перенормировке может давать другой локальный минимум из-за
численной чувствительности. Сравнение со старыми сохранёнными моделями
не заменяет сравнения с заново подобранным контролем.
