# Local paper calculations

This directory contains calculations performed on the local compute host for
this branch. The existing `paper/data` tables are historical server results,
not outputs of this local run. Do not mix timing measurements across hosts.
The calculation and NEST source files in `astrocyte_lab/` and
`experiments/fm_am_minimal_zones/` were selected from research commit
`1c5349188e9f6aa44fe7261d692f9120dab8541a`; local workflow adaptations are
tracked in this branch. `hardware.json` records the CPU and quota.

## Models and provenance

- Mixed-C fixed-fold and no-fold models for AM, AFM, FM are in
  `paper/figures/figure6_data/{fixed,no_fold}/{AM,AFM,FM}/parameters.json`;
  `figure6_data/provenance.json` records SHA-256 and source archives.
- The final frozen no-fold mixed FM candidate is absent: that exact JSON was
  only on the unavailable server. We use the earlier archive FM candidate
  (`44ea2b...`) and explicitly identify it in plots and benchmark metadata.
- Physical-C original seeds are `astrocyte_lab/paper_models/*_physical`;
  they had a constrained fold. `physical_no_fold_multistart/` contains new
  local unconstrained-fold refits (six starts per regime) and independent
  DOP853 checks; selected models are `*/comparison/new_rank_01/`.
  Fits are selected by training loss, not by holdout; their finite budgets
  and optimization status must be checked before using them in the article.
- The three mixed and three physical candidates are separately fitted. They
  are phenomenological approximations, not coordinate rewrites of one model.
- `cycle_errors.csv` summarizes the local independent validation. All six
  candidates have four out of four held-out cycles detected in this finite
  check. The FM physical candidate still has a relatively large held-out
  mean phase-aligned shape RMSE (about 0.205 µM), compared with about 0.068 µM
  for the older mixed FM candidate; equal cycle counts do not imply equal fit
  quality. LR targets used in the loss were archived seed data, and are not
  themselves regenerated by the physical fitting command. They were then
  independently recomputed locally: `lr_target_recalculation.json` contains
  33 of 33 resolved cycles; the largest absolute period difference from the
  archived targets is 3.6e-9 s and the largest phase-aligned waveform RMSE is
  6.0e-9 µM for this calculation.

## Commands

Create `.venv` with Python 3.12, NumPy 2.3.5, SciPy 1.17.0,
Matplotlib 3.10.8 and `nest-simulator==3.10.0`. NEST C++ extension headers,
CMake and a C++20 compiler are needed; the benchmark's `setup_build_tools.sh`
fetches pinned build tools and headers without system installation. The
computed module is generated per candidate and must be rebuilt for each one.

```bash
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONPATH=src
export MPLCONFIGDIR=/tmp/paper_local_mpl
.venv/bin/python scripts/paper_figure1.py
.venv/bin/python scripts/paper_mechanism_figures.py
.venv/bin/python scripts/paper_full_model_comparison.py --workers 2 --duration 600 --points 61
.venv/bin/python scripts/paper_continue_pwa_cycles.py --model-root . --workers 2 --steps 80
.venv/bin/python astrocyte_lab/experiments/physical_no_fold/run_server.py \
  --snapshot astrocyte_lab/paper_models --out paper/local_results/physical_no_fold_multistart \
  --starts 6 --workers 2 --powell-maxfev 6000 --ls-max-nfev 400 --validate-top 1
.venv/bin/python scripts/freeze_paper_local_models.py
.venv/bin/python scripts/paper_local_error_table.py
bash scripts/run_paper_local.sh
```

The full-comparison computation updates the forward trajectories. Both-cut
continuation, upper-only continuation and the near-fold boundary search are
recomputed locally with their `paper_continue_pwa_cycles.py`,
`paper_continue_upper_pwa.py` and `paper_fold_branches.py` scripts using
`--model-root .`. Some fold seeds originate from archived models. A finite
search is not a proof that no additional cycles exist.

`run_paper_local.sh` defaults to 60 s biological duration, dt 0.1 ms, 2
threads, and 3 same-seed repeats. It runs the 10-neuron/90-astrocyte
all-to-all benchmark at both 10 and 1000 ms recording intervals, then the
100-neuron scaling experiment. The source code and summaries specify the
closed-loop connectivity and SIC. These are whole-network timings; different
physical/mixed candidates, observation, SIC and network activity all affect
them. The scaling runs reuse the physical comparison's LR timing samples for
the mixed comparison after checking identical settings and topology; this is
one shared LR baseline, not an independent LR repeat for each candidate.
Timings should be collected while other heavy processes are idle.
