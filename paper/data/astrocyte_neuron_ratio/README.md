# NEST network timing versus astrocyte-to-neuron ratio

`timings.csv` contains the ten rows of `source_summary.json`, with ranges split into explicit minimum/maximum columns. Values retain the precision in the uploaded source. `coordinate` is the PWA calcium coordinate (`physical` or `mixed`), `ratio` is the number of independent astrocytes per neuron, and `astrocytes` is the total. `lr_median_s` and `pwa_median_s` are median wall-clock times for `nest.Run` in seconds; `speedup = lr_median_s / pwa_median_s`. Ratios are computed from the respective medians. Raw timing samples are **not present** in the uploaded aggregate; no dispersion or confidence interval can be recovered from this file.

## Protocol and interpretation

- Fixed 100-node excitatory `aeif_cond_alpha_astro` network, seeded recurrent connectivity (10 incoming neuronal connections per neuron); 100, 200, 400, 800 or 1600 astrocytes. The aggregate contains the neuronal edge SHA-256 `2936d71a60cc69689d675bf3347ae5a6978917c644e51780f2b373544ee73ab4`.
- FM case, K_ER=0.05 µM; Li–Rinzel versus separately fitted two-threshold PWA models in physical or mixed calcium coordinates, without a fixed fold. The source model paths and their hashes are **not present in this aggregate**; consult the detailed server summaries for exact provenance.
- Nominal settings used for this run: 60 s biological time, NEST resolution 0.1 ms, 16 threads, 3 repeats, one random seed, Poisson drive, SIC enabled. Each astrocyte received input from one neuron and sent SIC back to that neuron; SIC connection weight was divided by the astrocytes per neuron. Up to eight astrocytes were recorded at 10 ms intervals. See the experiment code in research commit `7338e9c`.
- `*_first_trace_peaks` counts detected calcium peaks in one recorded astrocyte during the **first repeat**. The C range is for that same astrocyte and the IP3 range is across sampled astrocytes in the first repeat; these are not estimates for all cells or repeats. Two PWA peaks over 60 s do not establish a converged period. The repeats use the same seed and are not independent network realizations.
- Astrocytes assigned to one neuron can have identical starting states and spike inputs; this is a diagnostic scaling experiment, not a statement about biological astrocyte counts. LR and PWA can produce different closed-loop activity. Therefore timing differences include neuronal work, SIC, recording, PWA dynamics and coordinate recovery; they do not isolate transformation cost.
