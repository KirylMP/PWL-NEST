# Фигура 1: нелинейная Li–Rinzel при постоянном IP₃

`figure1_li_rinzel.pdf` — векторный вариант для статьи;
`figure1_li_rinzel.svg` — редактируемый векторный вариант;
`figure1_li_rinzel.png` — растровый вариант, 600 dpi.
Подключение и английская подпись — `../figure1.tex`.

Верхний ряд: AM, K_ER = 0.1 мкМ. Нижний: FM, K_ER = 0.05 мкМ.
Слева — нульклины, направления поля и устойчивый цикл; в центре —
равновесия и экстремумы циклов; справа — периоды тех же циклов.
Для фазовых портретов I = 0.4 мкМ (AM) и 0.6 мкМ (FM).

Композиционный ориентир — Fig. 2 из De Pittà et al. (2009),
[DOI: 10.1007/s10867-009-9155-y](https://doi.org/10.1007/s10867-009-9155-y).
Все кривые заново рассчитаны из нелинейной модели репозитория, без оцифровки
изображения и без PWA-аппроксимаций. Исходная модель:
[Li & Rinzel (1994)](https://doi.org/10.1006/jtbi.1994.1041).
Подпись явно указывает источник композиции; результаты не заявлены как новая
бифуркационная структура Li–Rinzel.

## Воспроизведение

Из корня репозитория, в существующей среде Python:

```bash
OPENBLAS_NUM_THREADS=1 .venv/bin/python scripts/paper_figure1.py
make -C paper
```

Первая команда пересчитывает данные и рисунки; вторая собирает рукопись.
Перерисовка сохранённых данных без продолжения ветвей:

```bash
.venv/bin/python scripts/paper_figure1.py --plot-only
```

Зависимости — NumPy, SciPy и Matplotlib из `pyproject.toml`; дополнительные
пакеты продолжения не требуются. Версии пакетов и SHA256 скрипта сохранены
в `figure1_data/metadata.json`.

## Уравнения и параметры

Постоянный вход I = [IP₃]. Состояния C = [Ca²⁺] в мкМ и h безразмерно;
время в секундах. Используется `lr_field` из `src/pwl_nest/strict_pwa.py`,
совпадающий с `lr_rhs` из `src/pwl_nest/models.py`:

```text
m = I/(I+d1),  n = C/(C+d5),  Q = d2*(I+d1)/(I+d3)
dC/dt = (rC*m^3*n^3*h^3 + rL)*(C0 - (1+c1)*C)
        - vER*C^2/(C^2+KER^2)
dh/dt = a2*(Q - (Q+C)*h)
```

| Параметр | Значение | Единицы |
| --- | ---: | --- |
| C0 | 2 | мкМ |
| c1 | 0.185 | 1 |
| rC | 6 | с⁻¹ |
| rL | 0.11 | с⁻¹ |
| vER | 0.9 | мкМ/с |
| d1 | 0.13 | мкМ |
| d2 | 1.049 | мкМ |
| d3 | 0.9434 | мкМ |
| d5 | 0.08234 | мкМ |
| a2 | 0.2 | мкМ⁻¹ с⁻¹ |
| KER | 0.1 (AM), 0.05 (FM) | мкМ |

h означает доступность рецепторов после Ca²⁺-зависимой инактивации:
в данной записи доля открытых каналов пропорциональна m³n³h³.

Нульклина h вычисляется как Q/(Q+C). Нульклина C получается аналитическим
выделением h³ из первого уравнения; показана только физическая часть.
Серые стрелки имеют нормированную длину в координатах осей и показывают
направление, а не абсолютную скорость поля.

## Продолжение и проверка

1. Ветвь равновесий параметризуется C; I находится скалярным решением
   уравнения dC/dt = 0 после подстановки h = Q/(Q+C). Это сохраняет все три
   равновесия FM в области складок. Устойчивость определяется собственными
   числами аналитического якобиана.
2. Точки Хопфа находятся по trace(J) = 0 при det(J) > 0, складки равновесий —
   по det(J) = 0. Используется существующий `spectral_events`; его события
   `node_focus` не обозначаются бифуркациями и не отмечаются на рисунке.
3. Начальная периодическая орбита строится из собственного вектора в точке
   Хопфа и корректируется `solve_bvp`. Далее применяется псевдоаркленгс-
   продолжение полного профиля орбиты с неизвестными периодом T и входом I.
   Это позволяет проходить повороты ветвей и узкий канардный участок FM.
4. Фаза фиксируется условием dC/dt = 0 в максимуме C. Граничные условия
   требуют периодичности обоих состояний. Проверяется наличие одного
   максимума за период, а также C ∈ [0, 2/1.185] и h ∈ [0,1].
5. Для плоской автономной системы нетривиальный множитель Флоке имеет вид
   `log(mu) = integral_0^T trace(J(x(t),I)) dt`. Отрицательное значение
   соответствует устойчивому циклу, положительное — неустойчивому.
   Один тривиальный множитель равен 1 из-за инвариантности относительно
   сдвига по времени. Верхняя складка циклов уточняется отдельной краевой
   задачей с условием `log(mu) = 0`.
6. Каждая орбита проверяется независимым DOP853 за один период: вперёд
   для устойчивой и назад для неустойчивой. Требуется замыкание лучше
   2e-6 по максимальной абсолютной ошибке компонентов (C численно в мкМ)
   и отличие всего временного профиля меньше 1e-5. Базовые допуски IVP:
   rtol = 2e-11, atol = 2e-13, max_step = 0.06 с. Допуск коллокации — 1e-8,
   для уточнения складки циклов — 2e-9.
7. Дополнительно проверяются невязки равновесий, обеих нульклин и совпадение
   аналитического якобиана с независимой complex-step производной.

### Нижняя граница FM

При увеличении периода вблизи нижней границы FM вход I меняется на крайне
малые величины. Отрезки с большими периодами становятся чувствительны
к точности double: малая невязка коллокации сама по себе уже не гарантирует
замыкания независимого IVP при сохранённом I. Такие точки остаются в CSV
с `displayed=False` и не попадают на рисунок. Поле `ivp_waveform_error`
дополнительно проверяет совпадение профиля на всём периоде.

Поэтому крайняя точка показанной ветви — предел разрешённого расчёта,
а не численно установленная глобальная бифуркация. Тип и точное положение
нижнего глобального события по этим данным не утверждаются. В частности,
точки det(J) = 0 на ветви равновесий сами по себе не доказывают SNIC.

## Сохранённые данные

- `cycles.csv` — вход, период, C_min/C_max, log множителя Флоке,
  устойчивость, невязка коллокации, ошибки независимого IVP и признак
  включения в рисунок. Индекс соответствует орбите в NPZ своей ветви.
- `AM_upper_cycles.npz`, `FM_upper_cycles.npz`, `FM_lower_cycles.npz` —
  периодические профили, массив `orbits` формы `(число орбит, 2, 2001)`
  и нормированная фаза `phase` от 0 до 1.
- `*_equilibria.npz` — все равновесия с признаками устойчивости и седла.
- `*_phase_plane.npz` — независимо интегрированный цикл для фазового
  портрета, его I и период.
- `*_cycle_fold.npz` — профили уточнённых верхних складок циклов.
- `metadata.json` — параметры, события, версии и сводка проверок.

Условные обозначения: сплошная синяя линия — устойчивые равновесия;
пунктирная красная — неустойчивые, включая седла; чёрные и зелёные кружки —
максимумы и минимумы C на цикле. Заполненные кружки — устойчивые циклы,
пустые — неустойчивые. Квадраты отмечают точки Хопфа, ромбы — верхние складки
циклов. На панелях периодов используется та же устойчивость.
