# Три кандидата в NEST

Файлы AM_3zones, FM_4zones_6 и FM_4zones_7 предоставлены пользователем. Из корня репозитория с активированным окружением NEST 3.10:

```bash
export PWL_NEST_ROOT="$PWD"
NEST_THREADS=16 bash experiments/fm_am_minimal_zones/nest_mixed_power_ready/run_three_models.sh
```

Сценарий собирает модуль отдельно для FM6 и FM7, каждый раз используя тот же AM. Доступны настройки `NEST_DURATION_S`, `NEST_VALIDATION_S`, `NEST_RESOLUTION_MS`, `NEST_SINGLE_NODES`, `NEST_MULTI_NODES`, `NEST_THREADS` и `NEST_REPEATS`. Результаты сохраняются в `results/FM_6/` и `results/FM_7/`. `PWA_INIT_MODE=lr` воспроизводит прежний запуск с общим начальным состоянием; стандартный режим запускает PWA из собственного устойчивого равновесия. Для раздельного хранения двух режимов задавайте разные абсолютные пути `OUTROOT`.

Файлы кандидатов сохраняют исходный флаг `accepted`; проверка декодера и замер времени не подтверждают качество аппроксимации LR. Проверка обнаружения порогов по концам шага может пропустить несколько пересечений внутри одного шага.
