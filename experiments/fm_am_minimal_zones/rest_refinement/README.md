# Дополнительные пороги и точное равновесие при I=0

AM: исходные два порога и ещё два на одной и двух третях средней области, всего четыре. FM: исходные три порога и по два дополнительных внутри второй и третьей областей, всего семь. Все пороги физического C фиксируются до подбора. Каждая новая область наследует тип исходной: AM — устойчивость, неустойчивый фокус, устойчивый фокус; FM — устойчивый узел, седло, неустойчивый фокус, устойчивый фокус. Используются текущие исходные кандидаты с нелинейным преобразованием; карта подбирается вместе с остальными параметрами, физические пороги остаются неизменными.

Точные условия: C и h равновесия LR при I=0; пересечения равновесия с первым и последним исходными порогами при исходных фиксированных I. Из этих условий аналитически выражаются четыре коэффициента: две высоты нульклин, один коэффициент зависимости от I и один определитель дочерней области. Если полученный определитель нарушает заданный тип или его границы, кандидат отклоняется. Средний исходный переход FM сохраняет мягкий штраф. Нет гарантии, что одновременно существуют хороший fit и допустимая складка.

Из корня репозитория с активированным окружением:

```bash
bash experiments/fm_am_minimal_zones/rest_refinement/run_server.sh
```

Для отдельного прогона FM: `MODELS=fm bash experiments/fm_am_minimal_zones/rest_refinement/run_server.sh`. Создаётся новая папка результатов; предыдущий AM остаётся в своей папке. Если родительский FM не удовлетворяет новым точным условиям или физическим ограничениям на h в переходах, подготовка сначала ищет близкие допустимые параметры областей, сохраняя пороги и преобразование координаты. Это начальное приближение, а не результат подбора.

Для каждой модели последовательно: перенос родительских параметров с точным выполнением ограничений; подбор нульклин, равновесий и спектра; подготовка по возвращениям Пуанкаре; подбор по действительным корням и периодам/экстремумам. Для FM closed дополнительно использует численное условие складки большого цикла при `FM_FIXED_FOLD_I=1.1231503495944923` и штраф за обнаруженные лишние циклы. После этого конечный скан с графиком `candidate_bifurcation.png` и `candidate_branches.json` сравнивает модель с архивным LR. AM-эталон для циклов содержит устойчивую ветвь; конечная сетка не доказывает отсутствие других циклов.

Выполнение останавливается при невозможности инициализировать или независимо проверить FM складку; предыдущий кандидат и логи сохраняются. По умолчанию перед остановкой запускается его конечный скан и строится график; `VALIDATE_ON_CLOSED_FAILURE=0` отключает этот скан. Как и раньше, локальная проверка складки на предполагаемом маршруте не доказывает глобальное отсутствие других ветвей. `success` оптимизатора не является гарантией минимальности. Вся серия — исследовательский подбор, значение `accepted` сохраняется false.

Результаты в уникальной папке `results/rest_<UTC>_...`, её путь печатается как RUN_DIR. Там папки `am`, `fm`, `logs`. `AM_PARENT_CANDIDATE` и `FM_PARENT_CANDIDATE` выбирают родительские JSON с преобразованием и исходными порогами. `GEOMETRY_STARTS` (по умолчанию 4), `POINCARE_STARTS`, `CLOSED_STARTS`, `GEOMETRY_MAXFEV`, `POINCARE_MAXFEV`, `CLOSED_MAXFEV`, `POINCARE_WEIGHT_SCALE`, `FM_TARGET_GRID_SIZE`, `FM_CYCLE_COUNT_POINTS`, `FM_CYCLE_COUNT_SEEDS`, `FM_CYCLE_COUNT_WEIGHT`, `FM_FOLD_SOLVER_MAX_NFEV`, `VALIDATE_GRID_SIZE`, `VALIDATE_SEEDS` и `WORKERS` задаются окружением. Подбор последовательный; WORKERS используется только для независимых точек итогового скана.

Это ещё не NEST-прогон: генератор NEST из соседнего эксперимента пока принимает два AM или три FM порога и должен быть расширен отдельно.
