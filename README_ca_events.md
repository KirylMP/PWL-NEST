# Calcium threshold event benchmark

This experiment replaces SIC generation in both tested models with one NEST SpikeEvent when calcium is below the threshold at the beginning of a simulation step and at or above it at the end. The default threshold is 0.2 micromolar, separately configurable via `--threshold`. Initial calcium at or above threshold is not an event. Detection occurs once per upward crossing and is quantized to the NEST step; very short excursions within a step can be missed. Spike timestamps and routing follow NEST's normal SpikeEvent scheduler.

The LR event variant is derived from the original `astrocyte_lr_1994` implementation in NEST v3.10 (GPL-2.0-or-later); its integration settings are kept. The PWA event variant derives from this project's PWA NEST node. Both remove SIC evaluation and transmission. Timed simulations connect all astrocytes to a spike recorder, so recording and routing event overhead are included; diagnostic simulations additionally record calcium. Their behavior and performance should not be conflated with the built-in SIC models or the earlier no-recorder benchmark. Neither implementation is available for NEST runtime testing in the preparation environment: run the smoke test on the server before the benchmark.

Reproducibility and fairness: fixed calcium threshold, identical NEST time step, model inputs, node counts, event rule and output recorder. Event counts can differ because the trajectories differ. Timings contain PWA event counters. Compare recorded events to diagnostic calcium and compare LR and PWA trajectories to the previous run; use several fixed inputs. Results concern isolated astrocytes and recorder, not network speedup.
