# Дополнительный FM-поиск параметров

Проверены ещё три независимых старта в существующем 27-параметрическом семействе
с восемью областями. Сохранили точный устойчивый покой Li–Rinzel, все статические
ограничения, высоту и ширину пиков с допуском 10%, совпадение числа пиков и
ограничение средней ошибки фаз ≤1.75 с. Подбор шёл только по обучающим протоколам;
шесть новых входов использованы после выбора диагностического результата.

Лучший по обучающей целевой функции кандидат — `trials/control_0/candidate.json`:
его loss 16029.07 против 19141.12 у исходного кандидата, снижение примерно на
16.3%. На шести новых входах он сохранил физические траектории и совпадение числа
пиков 6/6, а средняя RMSE кальция снизилась с 0.19068 до 0.15612 мкМ (примерно
на 18.1%).

Кандидат не прошёл критерии приёмки. На обучающем `anchored_heldout_tau_48.0`
получено пять пиков вместо четырёх; из-за несовпадения числа пиков среднюю
фазовую ошибку нельзя корректно вычислить. Поэтому проверка формы прошла для 7
из 8 обучающих динамических протоколов, а фазовый gate не прошёл. Исходная модель
имеет ту же проблему с этим протоколом. Кандидат не заменяет incumbent и хранится
только как диагностика.

Все три старта и их checkpoints, конфигурация, входы, диагностики, сводка и
рекомендация до чтения новых тестов находятся в этом каталоге. Конфигурация
фиксирует лимит 1400 локальных оценок, 25 глобальных итераций, три направления
старта и сохранённые требования. Новые тесты: τ=12, 52, 150 и нерегулярные
последовательности при τ=19, 28, 40. Старые тесты τ=48 и 160 присутствуют в
исходном наборе обучения и не считаются независимыми.

Команда воспроизведения:

```sh
PYTHONPATH=src:scripts OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
  .venv/bin/python scripts/continue_anchored_fit.py \
  --output results/fm_more_search_20261021 --new-protocols irregular \
  --restarts 3 --budget 1400 --global-iterations 25 --workers 3 \
  --phase-ceiling 1.75 --timing-weight 3 --diverse-directions \
  --search-seed 20261120
```
