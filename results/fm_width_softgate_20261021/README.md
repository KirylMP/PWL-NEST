# Продолжение FM-подбора с мягким весом ширины

Проверили, насколько результат зависит от жёсткого динамического ограничения
на ширину пика. В обучающей функции ширина оставалась с мягким весом 0.25;
жёсткая проверка ширины 10% была отключена только для динамических пиков.
Проверки числа пиков, высоты (10%), фазы (MAE ≤1.75 с), точного устойчивого
покоя и статической формы/режимов оставались включены. Ширина записывалась
и в диагностические результаты. Выбрали кандидата до чтения новых входов.

Один из трёх стартов (`trials/control_0/candidate.json`) прошёл все остальные
обучающие условия. После подбора он прошёл и исходный строгий 10%-й критерий
ширины: максимальная ошибка ширины на обучающих динамических входах 8.66%,
высоты — 7.37%, 8/8 проверок формы и 8/8 статических проверок. Ошибка
абсолютного времени пиков — 1.439 с, ниже потолка 1.75 с. Точный LR-покой
сохранился.

На шести отложенных входах совпало число пиков во всех шести случаях. Средняя
ошибка траектории C изменилась с 0.15505 до 0.14878 мкМ (−4.0%). Результат
смешанный: нерегулярный вход улучшился (RMSE 0.31317 → 0.24644 мкМ), на τ=33 и
τ=54 ошибка выросла, а на остальных почти не изменилась. Максимальная ошибка
ширины на новых тестах — 8.79%. Поэтому эксперимент показывает, что отключение
жёсткого width gate не мешает найти допустимую модель; он **не** показывает, что
ширина биологически не важна, и не даёт заметного общего выигрыша в точности.

В blueprint нет самостоятельного требования «ошибка FWHM не более 10%».
Там обязательны общая динамическая точность, кальциевые траектории, пики,
задержка, возврат к покою, SIC и функциональные пороговые события. Ширина здесь
служит полезным сводным признаком формы; её практическая важность должна
определяться влиянием на траекторию, SIC и пороговые события. Поэтому 10% —
внутренний критерий этого проекта, а не требование blueprint.

Данные, конфигурация, все три попытки, checkpoints, новые тестовые траектории,
сравнения и рекомендация сохранены рядом. Для воспроизведения см. `config.json`
и команду в журнале родительского запуска.
