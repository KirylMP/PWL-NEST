# Paper NEST comparison: physical and mixed models without fold fixation

Six candidates: newly fitted `physical_no_fold` rank_01 models and frozen no-fold mixed models. Each has two thresholds, free q, and candidate hashes are recorded. The generated PWA NEST model treats the h_IP3R storage slot as unrestricted q, not LR h. Before network timing, each compiled model is checked against DOP853 at the equilibrium and in both directions at each threshold. K_ER for built-in LR is matched to each mode, including 0.075 for AFM. Each candidate is compiled in a separate sequential build and run in a new Python process.

All-excitatory all-to-all network: 10 neurons and 90 independent astrocytes; all astrocytes are recorded, with SIC active. Same seed and checked topology for every run. Recording intervals default to 10 and 1000 ms, with fixed 0.1 ms simulation resolution, 60 s and 3 repeats. Whole nest.Run includes NEST recording; slower recording means fewer recorded samples, not different integration resolution. Changing recording interval also changes event volume, so timing differences are not a direct isolated measurement of inverse-transform cost. In closed loop the distinct fits can give different calcium/SIC and spike histories; differences also include network and solver effects. Relative speed alone cannot demonstrate a transform-only causal cost.

Set PAPER_PHYSICAL_RUN / PAPER_SNAPSHOT if those paths differ. PAPER_RECORD_INTERVALS_MS, PAPER_DURATION_S, PAPER_DT_MS, PAPER_REPEATS, PAPER_THREADS, PAPER_NEURONS and PAPER_IP3_AM/AFM/FM adjust settings. Each run records its exact candidate JSON and SHA256, checked connectivity, timing samples, state checks, spikes and representative plots. Results are independent of frozen models, which are only read.
