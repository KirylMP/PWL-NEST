# Neuron / astrocyte scaling in NEST

A reproducible diagnostic network, not Makovkin's model. 100 excitatory `aeif_cond_alpha_astro` neurons with fixed seeded random indegree 10 and Poisson drive. Each neuron has r independent LR or PWA astrocytes. Each receives spikes from that neuron and sends SIC to that neuron; SIC weight is divided by r to keep the sum of connection weights per neuron fixed. This is synthetic scaling, not a biological claim about realistic numbers or compartments. Astrocytes sharing a presynaptic neuron start identically and have identical input, hence can synchronize exactly. Neuronal topology is generated deterministically and held fixed across r, model and repeats.

FM K_ER=.05; initial C=.7, h or q=.8, IP3=.6, with spike input delta_IP3=.0002; this lies in the previously tested FM oscillatory range but actual oscillations are not assumed: the first sampled astrocyte's peak count and C/IP3 ranges are reported per run, and NPZ traces are saved. Results apply only to these settings. The frozen mixed candidate and physical no-fold candidate are compiled separately; generated model supports free hidden q. Before each benchmark, threshold and equilibrium transitions are checked against DOP853. Direct and mixed trajectories, synaptic activity and SIC may differ in the closed-loop network; speedup is measured for whole nest.Run with recording and SIC, not pure ODE cost. Repeat runs have same seed and connectivity and do not represent independent network realizations.

Default r=1,2,4,8,16; 60 s, dt=.1 ms, 16 threads and three repeats. Outputs include summary.json, details and traces for both candidates, and speedup_vs_ratio.png. Parameters are controlled by ASTRO_RATIOS, ASTRO_NEURONS, ASTRO_INDEGREE, ASTRO_DURATION_S, ASTRO_DT_MS, ASTRO_THREADS, ASTRO_REPEATS, ASTRO_RECORD_MS, ASTRO_IP3, ASTRO_DELTA_IP3. See run.sh for PAPER_SNAPSHOT and PAPER_PHYSICAL_RUN input paths.
