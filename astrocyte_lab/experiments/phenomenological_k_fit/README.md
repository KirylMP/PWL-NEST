# Phenomenological two-threshold models across K_ER

Independent physical-calcium, identity-hidden-coordinate fits; one directory per K and regional-type construction. `fm` means a stable node in the lowest region; `am` means a stable focus. These names do not by themselves classify the oscillation as FM or AM.

Rest and both equilibrium crossings at the numerically located LR Hopf points are fixed exactly. The LR fold input and its amplitude are imposed using analytic PWA segment matching, zero integrated divergence, and C extrema. By default the itinerary crosses both thresholds, even when the LR fold cycle does not. `--itinerary auto` reproduces the old LR-based choice. Since a transverse cycle through both thresholds must have amplitude greater than their separation, incompatible cases are reported immediately; other failures do not prove infeasibility. The objective compares PWA and LR vector fields on a grid; no stable-cycle trajectory or period matching is included. No prior fit constraints are relaxed silently.

The stored LR fold targets come from `../lr_fold_vs_k/results_upper/fold_vs_k.json`; only matched K values with converged LR shooting are accepted. The LR continuation has not established uniqueness or nondegeneracy at every K. `verified_local` means finite segment admissibility, constraint residual, independent IVP closure and numerical local curvature and input unfolding checks passed. These checks do not establish global branch completeness, stability on both sides, or trajectory accuracy; finite difference checks can be ill conditioned. Failed checks are retained with diagnostics. All models, including failures, have independent logs. The plot only uses locally verified results. Inspect `summary.json` before interpreting parameter trends.

Example: `python3 -u astrocyte_lab/experiments/phenomenological_k_fit/run_family.py --workers 6 --starts 4 --maxiter 1200 --out astrocyte_lab/runs/k_family_example`.
