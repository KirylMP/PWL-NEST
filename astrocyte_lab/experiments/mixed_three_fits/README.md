# Two-threshold fits in mixed calcium coordinates

For each K_ER=0.05, 0.075, 0.10, compare the mixed monotone C coordinate to the corresponding uploaded direct-C model in `seeds/`. Both use the same physical C thresholds, I=0 rest, two LR equilibrium crossing inputs, LR fold input, and two-threshold fold itinerary. Neither applies a Poincare loss; the fold is enforced via affine boundary matching and M=1. A DOP853 fold-closure check and finite numerical nondegeneracy tests follow. Local stable and unstable cycles are searched around the fold; finite negative findings do not prove absence.

z=Phi(C), where Phi is the positive weighted sum of normalized power, exponential, and logarithm terms used in the prior mixed-coordinate models. The PWA is affine in (z,q); C is recovered by monotone numerical inversion. The same exact rest and event constraints are parameterized in z, with thresholds Phi(C_j). The state q is not transformed. Four shape parameters are fitted. The mixed-coordinate simulation operates in z and recovers physical C only for waveform samples. It is not a NEST speed benchmark.

Training uses the same seven source inputs as the direct-C experiment and the same normalized-phase C waveform and period loss, with four held-out inputs. `identity_comparison.json` compares the independent finite DOP853 runs against the original direct-C validation. Candidate seed is the original physical-C fit mapped approximately to an affine z, then perturbed; the mixed family approaches but does not exactly contain a pure affine map with finite bounded shape parameters. Optimizer success and absolute validation error should be inspected. Original validation used the same inputs but independent reruns may vary in tolerances and phase sampling. Source fold targets and finite cycle inventory are not proofs of global bifurcation structure. For AM the forced two-cut fold cannot have LR's Cmin, because LR's fold orbit does not cross the first physical cut.
