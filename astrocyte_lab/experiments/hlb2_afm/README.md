# AFM lower node-focus HLB2

The piecewise affine dynamics in latent z and q at fixed input I obey `dy/dt=A_r y+b_r I+c_r`. Near the fixed lower event I=I1, after shifting the boundary equilibrium and setting `y=(state-state_boundary)/(I-I1)`, the two-region dynamics and matching problem are independent of nonzero `I-I1`. This homogeneity supplies a local candidate family without attempting to resolve tiny absolute deviations from I1 in a conventional floating-point optimizer. It applies only while the trajectory remains in the same two regions and C stays within the physical inverse domain.

`check.py` checks stable-node / unstable-focus type, solves the two boundary flight times using high-precision `mpmath` exponentials (precision selected from the approximate growth), samples 401 points per segment for orientation, crossing region and extrema, and reports integrated divergence/log multiplier. The input window before the second threshold or physical C boundary is a sampled estimate, not a rigorous interval. Extremely small windows may be below float64 input resolution. The exact boundary crossing is represented using the computed float64 model coefficients; the small parameter scales and time growth make results sensitive to model coefficients, event residuals and initial conditions. If the solver fails or transversality is not established, the result is unresolved; do not infer nonexistence. No unstable branches or global cycle inventory are implied.

`results/afm_mixed.json` is a local calculation for the unchanged archived model, SHA-256 recorded. Estimated I-I1 upper range is about 3e-9 µM; it is not a result for the AFM physical model. Direct DOP853 at I-I1=1e-10 produced approximately 127.3 s and C extrema 0.0894–0.0968 µM, but in float64 this is a delicate cross-check, not a precision certificate. At I-I1=1e-4 the observed stable orbit crossed the second threshold and was not the local two-region orbit.

For both selected AFM models run `check.py --snapshot ... --physical-run ... --out ...`. Requires `mpmath`, NumPy and SciPy in the active server Python environment. References: D. Simpson, Twenty Hopf-like bifurcations, HLB2 theorem, https://arxiv.org/pdf/1905.01329 .
