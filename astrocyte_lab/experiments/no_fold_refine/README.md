# Refine previous random no-fold fits

Take the top N training candidates from each K of a previous `no_fold_three_fits` run, preserving their original independent random initialization. For each use the same physical thresholds, rest and two fixed event inputs and same stable-waveform and period loss; neither fold nor unstable-cycle constraint is used. There are two optimization stages: bounded Powell, followed by bounded least-squares with centered finite differences at an explicit nonzero absolute scale. The period and phase from the RK4 kernel are based on interpolated peak times, instead of quantized step numbers. Default step 0.01 s. These changes can improve numerical behavior but neither convergence nor global optimum is guaranteed. Loss is re-evaluated using the new discretization before and after, so compare within the same run.

The best physically valid evaluation with all training cycles is retained even if the optimizer ends at a worse point. DOP853 verifies finite stable trajectories on the same training and held-out inputs; `refined_vs_previous.json` compares errors with the previous random-run winner on the same I values. This is not a global cycle analysis or a NEST benchmark. `checkpoint.json` is an unverified intermediate. Progress and stages are recorded in each `fit.log`.
